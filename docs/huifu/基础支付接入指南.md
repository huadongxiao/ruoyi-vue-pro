支付接入指南
开发者根据使用场景按照文档指引，选择适合的基础支付产品；
如果只需要接入 微信 / 支付宝 / 银联 支付，可使用 极速版 快速接入；
可以和斗拱智能助手大头哥对话，输入“我要接入支付”，获得初步对接方案；
如以上方案无法解决你的需求，可咨询客户经理，或自行查看文档了解。
小程序支付
渠道	产品和文档	对应 API
微信	微信小程序支付	聚合正扫 T_MINIAPP
支付宝	支付宝 JS 支付	聚合正扫 A_JSAPI
抖音	抖音间连小程序支付	聚合正扫 Y_MINIAPP
公众号支付
渠道	产品和文档	对应 API
微信	微信公众号（JS）支付	聚合正扫 T_JSAPI
App 支付
渠道	产品和文档	对应 API
微信	微信 App 支付（间连）（推荐），稳定性优于 微信小程序支付	聚合正扫 T_APP
支付宝	支付宝正扫	聚合正扫 A_NATIVE
抖音	抖音直连 App 支付	聚合正扫 Y_APP
银联	银联线上收银台	银联在线收银台
快捷支付	快捷支付	快捷支付
H5 支付
渠道	产品和文档	对应 API
微信	微信公众号（JS）支付	聚合正扫 T_JSAPI
支付宝	支付宝正扫	聚合正扫 A_NATIVE
抖音	抖音直连 H5 支付
抖音间连 JS 支付	聚合正扫 Y_H5,Y_JSAPI
银联	银联 JS 支付	聚合正扫 U_JSAPI
快捷支付	快捷支付	快捷支付
网银支付	网银支付	网银支付
PC 支付
渠道	产品和文档	对应 API
微信	需要用户使用聚合正扫结合自身场景封装	聚合正扫
支付宝	需要用户使用聚合正扫结合自身场景封装	聚合正扫
银联	需要用户使用聚合正扫结合自身场景封装	聚合正扫
抖音	需要用户使用聚合正扫结合自身场景封装	聚合正扫
数字人民币	数字人民币支付，需要用户使用聚合正扫结合自身场景封装	聚合正扫
快捷支付	快捷支付	快捷支付
网银支付	网银支付	网银支付
扫码支付
渠道	产品和文档	对应 API
微信	微信公众号（JS）支付	聚合正扫 T_JSAPI
支付宝	支付宝正扫	聚合正扫 A_NATIVE
银联	银联正扫	聚合正扫 U_NATIVE
抖音	抖音间连小程序支付
抖音间连 JS 支付	聚合正扫 Y_MINIAPP,Y_JSAPI
付款码支付
渠道	产品和文档	对应 API
微信	微信付款码	聚合反扫 T_MICROPAY
支付宝	支付宝付款码	聚合反扫 A_MICROPAY
银联	银联付款码	聚合反扫 U_MICROPAY
